CRM Visit Route
===============

Módulo para gestionar visitas comerciales con:

* Planificación por plantillas.
* Zonas de visita.
* Generación de rutas en Google Maps.
* Captura de coordenadas (check-in / check-out) usando la API estándar de geolocalización del navegador.
* Vista de auditoría para revisar visitas ejecutadas con coordenadas registradas.
